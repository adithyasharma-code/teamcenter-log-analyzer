# Teamcenter Log Analyzer v5.0

Batch-based log analysis tool optimized for:
- Teamcenter RAC logs
- TC Server logs
- Dispatcher logs
- FMS / TCCS / AIF integration logs

## Features
- Category grouping (ERROR, WARNING, SLOW, PARTIALERROR)
- Module detection (RAC, BMIDE, FMS, SOA, ITK, etc.)
- CSV + TXT output
- Timestamp-based folder generation
- Multi-log support

## Usage
teamcenter_log_analyzer_v5.bat *.log /open
